# frontend/tasks.md — 프론트엔드 영역 작업 보드 (칸반)

> **이 파일의 역할**
> 프론트엔드 영역에 닫혀 있는 모든 작업 카드를 관리합니다. 두 영역 이상 얽히는 카드는 [`../base/tasks.md`](../base/tasks.md)에.
> 칸반은 **TODO → DOING → DONE** 세 컬럼만. 카드 형식과 운영 규칙은 [`../base/tasks.md`](../base/tasks.md) 상단 참고.

---

## 카드 형식 (재게시)

```
- [F-NN] 작업 제목 (한 줄)
  - owner: @담당자  | priority: P0/P1/P2
  - 컨텍스트: 왜 필요한가 1줄
  - 산출물: 무엇이 끝나면 DONE인가 (구체적) — 화면 캡처 / 사용자 시나리오로 정의 가능
  - 관련 파일: <컴포넌트/페이지 경로 — 스택 확정 후>
  - 참고 문서: claude/frontend/team-guide.md §X, claude/base/user-experience.md §X
  - 변경일: YYYY-MM-DD
```

- **scheme 접두**: `F-`. 번호는 영역 안에서 순차 증가.
- 스택 미확정 단계의 카드는 "스택 결정 후 착수" 표시를 owner 옆에 추가.
- 한 사람당 동시 DOING 카드 **최대 2개**.
