**1. 정렬 알고리즘 (Sorting Algorithms)**

**데이터를 특정 순서대로 나열하는 알고리즘들입니다**.

| **알고리즘 (영어명)**         | **평균 시간 복잡도**              | **최악 시간 복잡도**              | **특징 및 장단점**                                           |
| ----------------------------------- | --------------------------------------- | --------------------------------------- | ------------------------------------------------------------------ |
| **선택 정렬**(Selection Sort) | **Θ**(**n**2**)**          | **Θ**(**n**2**)**          | **매 라운드 최솟값을 찾아 교환**                             |
| **버블 정렬**(Bubble Sort)    | **Θ**(**n**2**)**          | **Θ**(**n**2**)**          | **인접한 원소끼리 비교 및 교환**                             |
| **삽입 정렬**(Insertion Sort) | **Θ**(**n**2**)**          | **Θ**(**n**2**)**          | **거의 정렬된 데이터에서**Θ**(**n**)**으로 가장 빠름  |
| **합병 정렬**(Merge Sort)     | **Θ**(**n**log**n**) | **Θ**(**n**log**n**) | **분할 정복 방식,**O**(**n**)**의 추가 공간 필요       |
| **퀵 정렬**(Quick Sort)       | **Θ**(**n**log**n**) | **Θ**(**n**2**)**          | **평균적으로 가장 빠르나 피벗 선택에 따라 최악 발생**        |
| **힙 정렬**(Heap Sort)        | **Θ**(**n**log**n**) | **Θ**(**n**log**n**) | **힙 자료구조 이용, 추가 공간 없는 제자리 정렬**             |
| **계수 정렬**(Counting Sort)  | **Θ**(**n**+**k**)   | **Θ**(**n**+**k**)   | **값의 범위(**k**)가 작을 때 사용하는 선형 시간 정렬** |
| **기수 정렬**(Radix Sort)     | **Θ**(**nk**)              | **Θ**(**nk**)              | **자릿수(**k**)별로 안정 정렬을 수행하는 방식**        |

**2. 탐색 및 선택 알고리즘 (Search & Selection)**

**특정 값이나 순위의 데이터를 찾는 알고리즘들입니다**.

| **알고리즘 (영어명)**              | **시간 복잡도**                                 | **특징**                                                        |
| ---------------------------------------- | ----------------------------------------------------- | --------------------------------------------------------------------- |
| **이진 탐색**(Binary Search)       | **Θ**(**lo**g**n**)                | **정렬된 배열에서 범위를 절반씩 줄이며 탐색**                   |
| **랜덤 선택**(Randomized Select)   | **Θ**(**n**)**(평균)**             | **k**번째 작은 원소 찾기, 최악 시**Θ**(**n**2**)** |
| **선형 선택**(Linear Select / MoM) | **Θ**(**n**)                             | **'중간값들의 중간값'을 이용해 최악에도 선형 시간 보장**        |
| **해시 탐색**(Hash Search)         | **O**(**1**)**(평균)**              | **해시 함수를 통해 인덱스로 직접 접근**                         |
| **BST 탐색**(BST Search)           | **O**(**lo**g**n**)**(평균)** | **이진 탐색 트리 구조를 따라 탐색, 최악 시**O**(**n**)**  |

**3. 탐욕 알고리즘 (Greedy Algorithms)**

**매 순간 최선의 선택을 하여 최적해를 찾는 방식입니다**.

| **알고리즘 (영어명)**              | **용도**                  | **시간 복잡도**                                                                        |
| ---------------------------------------- | ------------------------------- | -------------------------------------------------------------------------------------------- |
| **분할 배낭**(Fractional Knapsack) | **가치 합 최대화**        | **O**(**n**log**n**)**(정렬 포함)**                                  |
| **활동 선택**(Activity Selection)  | **최대 활동 수 선택**     | **O**(**n**log**n**)**(종료 시간 기준)**                             |
| **허프만 코딩**(Huffman Coding)    | **데이터 압축**           | **O**(**n**log**n**)**(최소 힙 이용)**                               |
| **크루스칼**(Kruskal's MST)        | **최소 신장 트리**        | **O**(**m**log**m**)**(간선 중심)**                                  |
| **프림**(Prim's MST)               | **최소 신장 트리**        | **O**(**n**2**)**또는**O**(**m**log**n**)**(정점 중심)** |
| **다익스트라**(Dijkstra's)         | **단일 시작점 최단 경로** | **O**(**n**2**)**또는**O**(**m**log**n**)                      |

**4. 동적 계획법 알고리즘 (Dynamic Programming)**

**부분 문제의 해를 저장하여 재사용하는 방식입니다**.

| **알고리즘 (영어명)**             | **용도**                  | **시간 복잡도**                                       |
| --------------------------------------- | ------------------------------- | ----------------------------------------------------------- |
| **피보나치**(Fibonacci DP)        | **수열 값 계산**          | **O**(**n**)**(메모이제이션/타뷸레이션)** |
| **행렬 경로**(Matrix Path)        | **최대 합 경로 찾기**     | **O**(**n**2**)**                               |
| **LCS**(최장 공통 부분 서열)      | **문자열 유사도 측정**    | **O**(**mn**)                                   |
| **0-1 배낭**(0-1 Knapsack)        | **물건 선택 가치 최대화** | **O**(**n**C**)**(용량**C**에 의존)       |
| **동전 거스름돈**(Coin Change DP) | **최소 동전 개수 구하기** | **O**(**nk**)                                   |
| **플로이드-워셜**(Floyd-Warshall) | **모든 쌍 최단 경로**     | **O**(**n**3**)**                               |
| **편집 거리**(Edit Distance)      | **문자열 변환 최소 비용** | **O**(**mn**)                                   |

**5. 기타 알고리즘**

| **알고리즘 (영어명)**             | **전략/카테고리**  | **시간 복잡도**                            | **특징**                                |
| --------------------------------------- | ------------------------ | ------------------------------------------------ | --------------------------------------------- |
| **유클리드 호제법**(Euclid's GCD) | **수학 / 재귀**    | **O**(**lo**g**n**)            | **두 수의 최대공약수 계산**             |
| **최근접 점 쌍**(Closest Pair)    | **분할 정복**      | **O**(**n**log**2**n**)**      | **평면상 가장 가까운 두 점 찾기**       |
| **트리 순회**(Tree Traversal)     | **트리 탐색**      | **Θ**(**n**)                        | **모든 노드 방문 (In/Pre/Post-order)**  |
| **레드-블랙 트리**(RBT)           | **균형 탐색 트리** | **O**(**lo**g**n**)            | **최악의 경우에도 높이 균형 보장**      |
| **B-트리**(B-Tree)                | **다원 탐색 트리** | **O**(**lo**g**M****n**) | **디스크 I/O 최소화 (DB/파일시스템용)** |
