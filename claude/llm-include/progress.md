# llm-include/progress.md — LLM 자료 영역 진행 이력

> **갱신 규칙 (반드시 지킬 것)**
> 이 파일은 **다음 두 경우에만** 갱신한다.
> 1. **사용 기술이 바뀔 때** — 템플릿 엔진, 프롬프트 포맷 표준, 자료 직렬화 형식, LLM 공급자/모델의 변경.
> 2. **별도의 지침이 추가될 때** — `claude/base/`의 일반 규칙과 별개로, llm-include 자료 영역에만 해당하는 결정이 굳어질 때.
>
> 프롬프트 문구 다듬기·new few-shot 케이스 1건 추가 같은 **콘텐츠 변경은 기록하지 않는다**. 자료 파일 자체의 메타 헤더와 git 커밋으로 충분하다.
